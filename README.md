# ST558_Homework9

Continuation of homework 8...

This repository analyzes the Seoul Bike Sharing data set to predict daily bike rentals using `tidymodels` in R. We analyze multiple models, including linear regression, LASSO, regression trees, bagged trees, and random forests, tuned with cross-validation, and compared using RMSE and MAE. The final best model is then fitted to the entire data set. Extra information about each model is also included through summaries, coefficient tables, and variable importance plots.
